# Evidence overview

Baseline release evidence was reviewed on 23 October 2026, with selected subsequent frozen engineering records reviewed on 28 October 2026. This is an evidence map, not a public experimental release.

| Evidence stream | Research value | Limit |
|---|---|---|
| Recorded predictive baselines and motion analysis | Makes reference quality, baseline choice and prediction limitations inspectable | Bounded development data; no universal advantage or anatomy claim |
| Real camera acquisition and measurement interfaces | Shows actual sensing integration work rather than a purely drawn architecture | Software success and complete geometric validity remain separate |
| Bounded SO-101 simulated tasks | Shows task engineering with a concrete simulated embodiment | Scene/contact assumptions; no physical robot claim |
| Visual re-observation in simulation | Examines the role of observing a changed task scene | Limited development settings; no validated high-level method advantage |
| Unresolved and adverse evidence | Guides what should not yet be claimed | Detailed unpublished comparisons remain private |

Exact source paths, hashes, conditions and numerical tables are held in a separate private audit. No private source file, real human record, research model or third-party asset is distributed here. A reviewer should read [research status](../RESEARCH_STATUS.md) before interpreting the [conceptual architecture](../ARCHITECTURE.md).
