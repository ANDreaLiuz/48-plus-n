# Research questions

1. **Preparation:** when does a forecast add useful information beyond a simple baseline, and when should an interface expose uncertainty or missing observation instead?
2. **Human authority:** how can anticipatory computation support the person while leaving task authority explicit?
3. **Embodiment:** which parts of a goal can remain meaningful across bodies with different capabilities, and which require new validation?
4. **Evidence:** how can recorded-data, software, simulation and physical results be communicated without implying that they establish the same thing?

These questions organize ongoing work. They do not establish novelty, superiority, hardware safety or arbitrary cross-body transfer.
